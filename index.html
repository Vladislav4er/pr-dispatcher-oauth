PR Review Dispatcher

Подбор ревьюверов с учётом доступности

pr-dispatcher помогает команде назначать ревьюверов на pull request, учитывая экспертизу, нагрузку и календарь отпусков.

Для чего нужен доступ к Google Sheets

Приложение читает настроенную владельцем таблицу отпусков и исключает недоступных участников из подбора. Если у ушедшего в отпуск ревьювера остались активные назначения, приложение может подобрать ему замену.

Подключение использует разрешение spreadsheets.readonly. Оно позволяет читать доступные Google-учётной записи таблицы. Приложение обращается к документу и вкладке, указанным в его настройках, и не изменяет Google-таблицы.

Как используется приложение

Это приложение для настроенной командной инсталляции. Оператор подключает свои системы проверки кода и Google-учётную запись с доступом к календарю. Этот сайт содержит описание приложения и условия обработки данных; подключение аккаунта выполняется через отдельный экран согласия Google.

Подробности о данных, получателях, хранении и отключении доступа приведены в политике конфиденциальности. Правила использования приведены в условиях использования.
